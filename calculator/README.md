# Calculator

A beginner-friendly calculator built with Python.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Handles division by zero

## Concepts Used

- Functions
- User Input
- Conditional Statements
- Basic Error Handling

## How to Run

```bash
python main.py
```
